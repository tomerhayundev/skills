# Feature announcement

Status: stub (nearest: promo). Read [promo](../promo/FORMAT.md), then apply the deltas below.

## Fits when

A single new feature or release: "new", "now you can", "changelog", "release". Several features at once is a product demo.

## Lengths and platforms

30 s default, 15-60 s. Reels, LinkedIn, X, YouTube Shorts, the changelog page. A 6-15 s teaser before release day.

## Story shape

Hook: "New:" plus what the viewer can now do (1-3 s) · before (the old way, 3-5 s) · after (the feature doing it, the turn on the lift) · how to get it (CTA).

## Assets and voice

The feature running in the real product; before and after on the same screen so the change is visible. No voice by default.

## Engine profile

The promo profile unchanged.

## Build notes

Before and after share one element (a shared element or a morph), so the change reads as the same screen improving.

## Verification

The promo checks. At most 3 items even when the release has more.

## Common mistakes

| Mistake | Fix |
| --- | --- |
| Listing every change in the release | One feature per video, the rest in the post |
