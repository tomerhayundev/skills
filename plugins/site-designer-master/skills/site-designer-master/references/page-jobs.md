# Page jobs and conversion

Every page and every section exists for a reason a visitor would recognise. Name it before building it.

| Rule | Check |
| --- | --- |
| **The 5-second test.** The first screen says what this is, who it is for, and what to do next. The headline names the offer concretely; a clever line may follow, never lead. | the critic, on first-375.png and first-1440.png |
| **One primary action per view.** One filled button per section; the second action is a text link. | meter rule PRIMARY_PER_VIEW |
| Button text is a verb plus an object: what happens when it is pressed. Never "Submit", "Learn more", "Click here". | meter rule BUTTON_TEXT |
| **Proof sits next to the ask:** a review, a number from the brief or a real photo beside each primary button after the hero. | the critic |
| Answer the brief's objections (price, time, risk, "is it for me", "how does it work") before the final ask. A FAQ uses real questions. | the brief's objections list against the pages |
| Section order follows the visitor's questions (see the brief), never a stock order of hero, logos, three features, testimonial, pricing, call to action. | the brief records the order and why |
| Show prices when the business can; "from" a price beats "contact us". One plan marked as recommended; annual and monthly totals honest. | |
| No fake urgency: no countdown that resets, no "only 2 left" without a source, no invented counts. | meter rule UNSOURCED_NUMBER, the critic |
| The contact or booking form is one tap from any page. | header and footer |

Every decision on the way to the action (which item, which day, how many) follows [decisions](decisions.md):
smart defaults, a button that says the result, value before the ask, real losses only.

## Modes set how much ambition a page carries

| Mode | Pages | Ambition |
| --- | --- | --- |
| Persuade | home, landing | One signature idea from the client's own things; one authored motion moment; large type and real pictures. |
| Experience | portfolio, launch | The most room for the idea; the work itself is the hero. |
| Operate | shop, booking, forms, account | The world lends type, palette and one detail; navigation and controls stay standard. Feedback motion only. |
| Read | articles, docs, legal | Measure, leading and contrast first; nothing moves near reading text. |
