# Accessibility

WCAG 2.2 AA is the floor. The meter runs the vendored axe-core scan at 375 and 1440 on every page and fails
on any serious or critical issue (AXE_SERIOUS); the rules below are what the scan cannot judge alone.

| Rule | Check |
| --- | --- |
| Landmarks: one `main`, a header, navigation and a footer; a skip link as the first focusable element. | meter rule LANDMARKS; the site kit |
| `lang` and `dir` on `<html>` (Hebrew: `lang="he" dir="rtl"`). | meter rule LANG_DIR |
| Alt text says what a content image shows; a decorative image has `alt=""`. | meter rule IMG_ALT |
| Headings in order, one h1. | meter rules H1_COUNT and HEADING_SKIP |
| Every action works by keyboard alone, in visual order, with a visible focus ring (2.4.7) that a sticky header never hides (2.4.11). | keyboard walk; axe |
| Targets at least 24x24 CSS px (2.5.8). | meter rule TARGET_SIZE |
| Contrast: text 4.5:1, large text 3:1, controls and focus rings 3:1. | meter rule CONTRAST; tokens.mjs |
| Colour is never the only signal. | the critic |
| Text resizes to 200% and reflows at 320px without loss (1.4.10); text-spacing overrides do not break layout (1.4.12). | the meter at 320 |
| Help and contact sit in the same place on every page (3.2.6); sign-in allows paste and password managers (3.3.8); nothing asks for the same information twice (3.3.7). | |
| Motion respects reduced motion. | meter rule REDUCED_MOTION |

Some countries require an accessibility statement on business sites (Israel among them). When the brief's
country requires one, add an accessibility statement page linked from the footer, written in plain words:
what was done, known gaps, and how to report a problem.
