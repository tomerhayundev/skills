# Icon sets shown in the picker

Each sheet in this folder draws 12 unmodified glyphs from one open-licence icon set, fetched from its published package.

- round-outline-a.html: https://lucide.dev (ISC), package path lucide-static/icons
- round-outline-b.html: https://tabler.io/icons (MIT), package path @tabler/icons/icons/outline
- regular-outline.html: https://phosphoricons.com (MIT), package path @phosphor-icons/core/assets/regular
- thin-outline.html: https://phosphoricons.com (MIT), package path @phosphor-icons/core/assets/thin
- solid-soft.html: https://phosphoricons.com (MIT), package path @phosphor-icons/core/assets/fill
- outline-ui.html: https://heroicons.com (MIT), package path heroicons/24/outline
- solid-ui.html: https://heroicons.com (MIT), package path heroicons/24/solid
- simple-line.html: https://feathericons.com (MIT), package path feather-icons/dist/icons
- line-geometric.html: https://iconoir.com (MIT), package path iconoir/icons/regular
- classic-ui.html: https://icons.getbootstrap.com (MIT), package path bootstrap-icons/icons
- mobile-outline.html: https://ionic.io/ionicons (MIT), package path ionicons/dist/svg
- system-outlined.html: https://fonts.google.com/icons (Apache-2.0), package path @material-symbols/svg-400/outlined
- system-rounded.html: https://fonts.google.com/icons (Apache-2.0), package path @material-symbols/svg-400/rounded
- soft-outline.html: https://akveo.github.io/eva-icons (MIT), package path eva-icons/outline/svg
- office-regular.html: https://github.com/microsoft/fluentui-system-icons (MIT), package path @fluentui/svg-icons/icons
- pixel.html: https://pixelarticons.com (MIT), package path pixelarticons/svg
- dense-outline.html: https://pictogrammers.com/library/mdi (Apache-2.0), package path @mdi/svg/svg
